# 月牙雪熊桌宠 MVP 技术方案

## 1. 方案范围

本方案服务于《产品设计文档》中的 Windows 桌宠 MVP，仅支持 Windows 10/11，不引入云端服务、账号体系或数据库。首版优先保证桌宠稳定显示、动画切换、鼠标互动、自动行为、右键菜单和本地设置恢复。

## 2. 技术栈

| 层次 | 选择 | 用途 |
|---|---|---|
| 运行时 | Python 3.12+ | 应用逻辑和工具链 |
| 桌面 UI | PySide6 / Qt 6 | 无边框窗口、透明背景、事件和菜单 |
| 动画 | PySide6 `QMovie` | 播放现有 GIF 动作素材 |
| 配置 | Python `json` + Qt 路径 API | 保存位置、大小、透明度、状态等设置 |
| 日志 | Python `logging` | 记录启动、状态切换、资源和保存错误 |
| 测试 | pytest + pytest-qt | 业务逻辑、状态机和 Qt 交互测试 |
| 打包 | PyInstaller | 生成 Windows 可分发程序 |
| 版本管理 | Git | 代码、素材和文档版本追踪 |

不使用 Electron、Web 服务或远程 API，避免为轻量桌宠引入额外运行时和网络依赖。

## 3. 应用结构

代码按职责拆分，避免把窗口事件、动画控制和自动行为全部写在一个窗口类中：

```text
src/
  main.py                 # 程序入口和 Qt 应用初始化
  app/
    settings.py           # 设置模型、默认值和 JSON 读写
    states.py             # 动作状态枚举和状态转换规则
    behavior.py           # 自动行为定时器和行走边界
    interaction.py        # 点击、按住、连续点击和拖动判定
    assets.py             # 素材路径和资源校验
  ui/
    pet_window.py         # 透明桌宠窗口和 GIF 播放
    context_menu.py       # 右键菜单和动作菜单
    tray.py               # 系统托盘、显示/隐藏和退出
tests/
  ...
assets/
  月牙雪熊/
```

实际目录可以随项目演进调整，但状态规则、持久化和 UI 应保持可独立测试。

## 4. 窗口与显示

- 使用 PySide6 的无边框顶层窗口。
- 使用透明窗口属性，只绘制角色 GIF 的可见区域，不绘制额外背景内容。
- 使用窗口置顶属性实现“置顶”开关。
- 通过窗口位置和尺寸 API 支持拖动与缩放。
- 通过窗口透明度属性实现整体透明度调整。
- 隐藏时保留进程和当前状态，恢复时重新显示同一个窗口。
- 角色资源使用项目内相对路径，打包后通过资源定位函数解析路径。

## 5. 动作与状态管理

动作状态统一由状态模型管理，首版包含：待机、行走、放松、警觉、受击、睡觉、生气。

- 每个状态关联一个 GIF 素材和播放策略。
- 临时动作播放完成后回到待机或行走。
- 用户操作优先级高于自动行为，可打断自动状态切换。
- 暂停自动行为时停止行走和随机切换，但仍允许菜单和鼠标触发动作。
- 状态切换由单一控制器执行，避免多个定时器同时修改当前动作。
- 素材缺失、加载失败或播放结束时记录日志，并回退到待机状态。

## 6. 自动行为与交互

- 使用 Qt 定时器驱动自动行为，不阻塞 UI 线程。
- 行走范围根据屏幕可用区域计算，限制在屏幕底部或配置的边界内。
- 无互动计时达到阈值后进入睡觉状态。
- 单击触发放松或积极反馈；连续点击触发受击；特定互动只触发生气。
- 按住鼠标时跟随鼠标移动，不触发额外动作。
- 拖动和动作点击需要区分，避免拖动桌宠时误触发动作。

## 7. 本地配置

配置使用 JSON 文件，建议放在 Windows 用户应用数据目录。首版保存：

```json
{
  "position": {"x": 0, "y": 0},
  "size": {"width": 180, "height": 180},
  "opacity": 1.0,
  "topmost": true,
  "auto_behavior_paused": false,
  "current_state": "idle"
}
```

启动时读取并校验字段；缺失或损坏时使用默认值。退出前保存，位置、大小、透明度和当前状态保存失败时写入日志，不阻止程序退出。

## 8. 资源与打包

- 现有 GIF、PNG 素材纳入应用资源清单。
- 开发环境使用项目目录中的 `月牙雪熊/`；打包环境使用 PyInstaller 的资源目录。
- MVP 初期优先生成 one-folder 包，便于检查素材和定位运行问题；稳定后再评估 one-file 包。
- Windows 打包产物应包含启动程序、素材目录和默认配置说明。
- 暂不制作安装器、自动更新和开机启动；这些属于后续迭代。

## 9. 测试策略

- 单元测试：状态转换、临时动作回退、连续点击判定、行走边界、配置读写和损坏配置恢复。
- Qt 交互测试：窗口显示/隐藏、菜单触发、拖动、透明度和置顶状态。
- 资源测试：逐一检查动作状态对应素材存在且可加载。
- Windows 验收：在 Windows 10/11 上启动、退出、重启恢复设置，并验证打包产物可独立运行。
- 每次功能改动都先运行自动化测试，再进行一次手动桌面交互验收。

## 10. 实施顺序

1. 建立 Python 项目、依赖和资源路径。
2. 实现透明桌宠窗口、GIF 播放和拖动。
3. 实现状态控制器与动作菜单。
4. 加入自动行为、暂停和鼠标互动。
5. 加入托盘、配置保存和重启恢复。
6. 用 PyInstaller 生成 Windows 包并按验收标准测试。

## 11. 暂不纳入 MVP

- macOS/Linux 跨平台支持
- 云端同步、账号和联网能力
- 声音系统和复杂养成逻辑
- 多角色、多套服装和插件机制
- 自动更新、开机启动和安装器体验
